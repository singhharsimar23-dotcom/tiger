FraudSight: Autonomous Graph-Augmented Fraud Investigation

A high-performance agentic investigation system combining TigerGraph native graph database, LangGraph multi-hop DAG reasoning, Google Gemini 2.5, and an information-theoretic Minimum Description Length (MDL) Sufficiency Gate to detect syndicated financial crime rings.

1

TigerGraph Core

Native graph storage over IEEE-CIS transaction and identity data. Deep BFS k-hop traversals uncover hidden multi-account collusion networks via derived SHARES_DEVICE and SHARES_EMAIL_DOMAIN edges.

2

LangGraph Workflow

An 8-node cyclic state machine coordinating alert ingestion, multi-hop topology expansion, tool-based evidence synthesis, institutional policy enforcement, and audit dossier creation.

3

MDL Sufficiency Gate

Solves the AI "over-investigation" trap. Uses Minimum Description Length principles to balance evidence compression against query cost, preventing endless tool loops and optimizing latency.

Audit-Ready Compliance Standard

Every completed investigation produces 4 canonical forensic output artifacts saved under outputs/cases/case_XX/:

  • case_record.json: Complete investigation ledger, evidence weights, MDL scores, and multi-turn decision log.
  • sar.json: Suspicious Activity Report formatted to FFIEC / FinCEN regulatory specifications with full narrative summary.
  • action_before.json: Pre-investigation baseline policy posture (e.g. Flag for Review).
  • action_after.json: Post-investigation escalated posture (e.g. Freeze Account, Supervisor Tier).
